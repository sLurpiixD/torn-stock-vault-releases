# Torn Stock Vault

[Install or update the GitHub edition in Tampermonkey](https://raw.githubusercontent.com/sLurpiixD/torn-stock-vault-releases/main/torn-stock-vault.user.js). Enable a single copy of the vault and reload Torn’s Stocks page.

Version 0.2.0 restores the original Smart Stock Vault 10.2.17 interface and executable code. The userscript name and namespace identify existing fork installations. The fork version and update links support GitHub distribution. The goal planner from 0.1.x is retired for this baseline.

The original script uses jQuery, Torn’s API and Tornsy. Tampermonkey may prompt for additional permissions when upgrading from the planner. Upstream features include trading controls. The original settings and data storage behavior apply.
