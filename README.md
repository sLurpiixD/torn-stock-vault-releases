# Torn Stock Vault

[Install or update in Tampermonkey](https://raw.githubusercontent.com/sLurpiixD/torn-stock-vault-releases/main/torn-stock-vault.user.js). Confirm the installation, then reload Torn’s Stocks page. The vault plans deposits, withdrawals and rebalancing while protecting shares reserved for a block goal. You place trades using Torn’s controls. No API key is required.

Tampermonkey checks this repository for newer published versions according to your extension settings.
